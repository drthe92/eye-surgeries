# Template bài học phẫu thuật

Copy toàn bộ thư mục này thành `surgeries/<ten-phau-thuat>/` cho mỗi video mới.

## Cấu trúc
- `transcript.md`: metadata + transcript nguyên văn + nguồn.
- `steps.md`: bản chất, lịch sử ngắn, steps theo video, giải phẫu, biến chứng.
- `checklist.md`: chỉ định/chống chỉ định, chuẩn bị, dụng cụ, hậu phẫu, câu hỏi tự lượng giá.

## Quy trình với OpenChamber
1. Lưu link YouTube + Vimeo + trang companion EyeRounds/EyeForum.
2. Chiết steps-raw đối chiếu timestamp.
3. Mở rộng từng module có trích nguồn.
4. Tự kể lại để AI chấm thiếu đủ.
5. Đặt schedule ôn biến chứng/chăm sóc hậu phẫu cách ngày.
